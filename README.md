# Мастер бусин

Программа на русском для создания бусин для паракорда без навыков 3D-моделирования. Работает локально в браузере; все библиотеки и CAD-ядро находятся на компьютере. Интернет для работы не нужен.

## Запуск на Windows

1. Скачайте `BeadStudio-Windows-x64.zip` со страницы **Releases** и распакуйте **весь архив**.
2. Откройте папку `BeadStudio`, дважды нажмите `BeadStudio.exe`. Откроется браузер.
3. Выберите форму, ширину, высоту и отверстие. Вращайте бусину мышью, меняйте масштаб колесом.
4. Нажмите **Файл для печати**, откройте STL в слайсере: миллиметры, 100%, отверстие вертикально.
5. Для выхода нажмите **Выйти**. После закрытия всех вкладок программа завершится примерно через 5 минут.

Python, Fusion и другие 3D-редакторы для работы с EXE не требуются. Сохраняйте настройки кнопкой **Сохранить настройки**, чтобы вернуться к модели позже. Файл настроек можно передать другому пользователю программы.

## Что можно создать

- A — гладкая бочка;
- B — тактическая с десятью продольными канавками;
- C — шестигранная;
- D — три спиральные канавки, настройка глубины и закручивания;
- E — двенадцатигранная с суженными торцами;
- F — руническая, настройка глубины орнамента;
- G — четыре сегмента с кольцевыми канавками;
- H — коническая.

Ширина 12–20 мм, высота 12–24 мм, отверстие 4–10 мм (по умолчанию 6 мм). На обоих входах отверстия — фаска 0,5 мм. Программа отвергает сочетания, у которых расчётный запас стенки меньше 1,2 мм. Это консервативная геометрическая оценка, а не проверка прочности материала.

## Сохранение

| Кнопка | Результат |
|---|---|
| Файл для печати | STL в миллиметрах, из реально построенного CAD-тела |
| Открыть в 3D-редакторе | STEP с точными поверхностями, без истории параметров |
| Редактировать в Fusion | ZIP со скриптом, выбранной формой и размерами; запуск в Fusion создаёт параметрическую историю |
| Сохранить настройки | Небольшой `.bead.json`, который можно загрузить обратно |

Для Fusion распакуйте ZIP, откройте `START_HERE.txt`. В Fusion: **Utilities → Scripts and Add-Ins (Shift+S) → Scripts → +**, добавьте папку `Paracord550`, выполните скрипт. Размеры доступны в **Modify → Change Parameters**. Параметрический F3D создаётся при успешном запуске скрипта; ZIP не выдаётся за готовый F3D. Запуск скрипта и пересчёт параметров непосредственно внутри Fusion отдельно не подтверждены.

Предпросмотр показывает тот же STL, который сохраняется на диск. Каждая генерация строит точное тело OpenCascade и проверяет его корректность и связность. Ошибка или изменение настроек блокируют экспорт предыдущего результата.

Сначала напечатайте одну бусину и проверьте проход вашего шнура. Печать на физическом принтере и прочность деталей не проверялись. При необходимости увеличьте отверстие с учётом точности принтера. Для двух ветвей подберите размер по фактическому пучку.

## Разработчику

Python 3.11 x64 и Node.js 20+:

```powershell
py -3.11 -m venv .venv
.venv\Scripts\python -m pip install -r requirements-dev.txt
npm ci
npm run vendor
.venv\Scripts\python launch.py
```

Готовые браузерные зависимости включены в репозиторий; `npm ci` нужен только для их обновления и UI-тестов. Для простого запуска исходников достаточно установить `requirements.txt` и выполнить `launch.py`.

Проверки и переносимая Windows-сборка:

```powershell
.venv\Scripts\python -m pytest -q
npx playwright install chromium
npm run test:ui
.venv\Scripts\python -m PyInstaller --noconfirm BeadStudio.spec
.venv\Scripts\python tools/package_release.py
```

Браузерный тест запускает Python из `.venv`; для другого окружения задайте `BEAD_PYTHON`. CI выполняет геометрические и HTTP-проверки, UI-тест и проверку собранного EXE. Тег `v*` создаёт GitHub Release с Windows ZIP. В Windows требуется сохранять папку `_internal` рядом с EXE.

Процесс слушает только `127.0.0.1` на свободном порту, имеет случайный адрес сеанса и проверяет Origin для изменяющих запросов. Модели создаются во временной папке, которая удаляется при нормальном выходе. Логи ошибок: `%LOCALAPPDATA%\BeadStudio\app.log`. Сервер принимает только ограниченный набор числовых размеров, не исполняет загруженный пользователем код.
