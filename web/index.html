НАЧНЁМ С ПРОСТОГО

Ваша первая бусина

  1. Выберите форму. Все восемь вариантов уже готовы к настройке.
  2. Задайте ширину, высоту и отверстие. Потяните ползунок или введите число. Модель обновится сама.
  3. Нажмите «Файл для печати». Откройте STL в вашем слайсере: миллиметры, 100%, отверстие вертикально.

STEP подходит для дальнейшей работы в 3D-редакторе. Кнопка Fusion скачивает скрипт с вашими параметрами; внутри ZIP есть инструкция запуска. Это не готовый файл F3D.

Чтобы продолжить позже, сохраните настройки. Файл можно загрузить обратно в эту программу.

Для выхода используйте кнопку «Выйти». После закрытия всех вкладок программа завершится примерно через 5 минут.
